# Remote Deck TV support

Public, account-independent support documentation and privacy policy for Remote Deck TV.

GitHub Pages: https://l1gh7c0d35.github.io/tv-remote-support/

- privacy.html: local preferences, permission, saved pairing, optional integrations and retention.
- support.html: local Wi-Fi discovery, TV pairing troubleshooting and contact through public GitHub issues.
- index.html: accessible navigation for both pages.

This repository does not contain private TV-Remote app source code, Apple API keys, pairing data, reviewer emails or unsupported claims of physical TV compatibility.
